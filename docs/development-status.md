# 개발 현황

> 갱신일: 2026-07-29
> 기준 문서: `production-roadmap.md`, `game-design-document.md`, `technical-design-document.md`

이 문서는 기획 변경을 위한 문서가 아니라, 설계 문서가 Unity 프로젝트에 어디까지 반영됐는지 기록하는 작업 현황표다.

## 현재 단계

- M0 프로젝트 기반: 완료
- M1 로컬 버티컬 슬라이스: 완료
- M2 네트워크 기반: 진행 중 — 인증과 Relay 방 생성·코드 참가 기반 구현 완료
- M3 이후: 시작 전

## 이번 구현 완료

### 플레이어와 카메라

- `WASD` 이동
- 마우스 위치를 향한 캐릭터 회전
- 회전하지 않는 고정 쿼터뷰 추적 카메라
- `CharacterController` 기반 벽 충돌
- `F` 손전등 켜기·끄기

### 맵과 상호작용

- 연구소 10개 방 회색 박스 유지
- 각 방 외곽 벽과 통로 출입구 충돌 생성
- 6개 시작점 중 첫 번째 위치에 로컬 플레이어 배치
- 거리 기반 상호작용 대상 탐색
- 화면 하단 `E` 상호작용 안내
- 전력 복구실 퓨즈 스테이션 배치
- 번호와 색상을 함께 표시하는 3개 퓨즈 순서 미니게임
- 잘못된 퓨즈 선택 시 즉시 실패하고 다시 상호작용해 재시도
- 성공 시 스테이션 표시등과 본체 색상 복구
- 미션 중 이동·조준 잠금, `Esc` 취소 후 입력 복구
- 퓨즈 오답 1회마다 `Medium` 소음 사건 1회 발행
- 퓨즈 실패 소음은 전력 복구실 기준 NavMesh 경로 거리 14m까지 전달

### 소음과 괴물 AI

- 시작 후 30초 동안 괴물은 순찰만 하고 소음 조사·추격·물기 비활성화
- 연구소 회색 박스 맵용 NavMesh 베이크 및 재빌드 시 에셋 GUID 유지
- 전력 복구실·격리실 동쪽 구간을 순찰하는 프로토타입 원숭이 1마리 배치
- 순찰 속도 2.6m/s, 방 체류 6±1초
- 소음 조사 시작 속도 6.0m/s, 최대 가속 6초 후 순찰 속도로 감속
- 소음 지점 도착 후 3초 탐색하고 다시 순찰
- 경로 거리, 소음 크기, 최신 시각, 작은 `noiseId` 순서의 결정적 우선순위 적용
- 시야 7m·100°와 장애물 레이캐스트를 모두 통과하면 플레이어 추격
- 벽 너머에서도 같은 NavMesh 층의 후각 반경 0.5m 안이면 플레이어 추격
- 후각 강화 0.5/1/2m, 괴물 수 4/6/8, 감염 제한 90/60/30초를 `SO_MonsterTier_Default`에 연결
- 추격 속도 4.6m/s, 표적 상실 시 마지막 위치에서 3초 수색
- 0.9m 안에서 시야를 재검사하고 0.35초 준비 후 물기 판정
- 물기 후 1.2초 재행동, 피격자에게 1.5초 재물림 보호 적용
- 소음 발생 배너와 상태별 프로토타입 색상 표시

### 감염과 해독제 사용 기반

- 생존자가 물리면 당시 독성 단계에 따라 90/60/30초 감염 즉시 시작
- 감염 시작 시 제한시간을 고정하고 이후 독성 강화나 재물림으로 초기화하지 않음
- 회의 연결을 위한 감염 타이머 정지·재개 인터페이스 준비
- 타이머 0에서 `DeadGhost` 상태로 전환하고 괴물 감지 대상에서 제외
- 감염 HUD에 남은 시간, 해독제 보유 여부와 사용 진행률 표시
- `R`로 1.5초 사용, 이동 입력 시 취소·미소비, 완료 시 한 개 소비 후 치료
- 소지 한도 1개를 `SO_AntidoteBalance_Default`에 연결
- 해독제 레시피·제작기·획득·보관은 M5 범위이며 현재 일반 플레이에서는 시작 소지품을 지급하지 않음

### 온라인 서비스 시작 기반

- `00_Bootstrap`에서 Unity Services 초기화 후 익명 인증을 순서대로 실행
- 중복 초기화 요청은 같은 작업을 공유하고, 이미 로그인된 세션은 SDK 재호출 없이 재사용
- 인증 성공 후 Player ID가 존재할 때만 다음 씬으로 전환
- 실패 시 Bootstrap에 머물며 사용자용 오류와 `다시 시도` 버튼 표시
- Unity Cloud 프로젝트 미연결 상태는 SDK 호출 전에 감지하고 연결 위치 안내
- Bootstrap 전용 카메라로 편집기와 빌드에서 오류 안내 화면을 동일하게 표시

### MPS Session과 Relay

- `01_MainMenu`에 `NetworkManager`, `UnityTransport`, `GameSessionController` 구성
- 호스트 포함 최대 6명의 비공개 MPS Session을 Relay 네트워크로 생성
- 참가 코드의 공백 제거·대문자 정규화 후 코드 참가
- 생성·참가 중 연속 입력은 같은 진행 작업을 공유해 SDK 중복 호출 방지
- 성공 시 참가 코드, 현재 인원, 최대 인원, 호스트 여부 표시
- 빈 코드, 만료 코드, 참가 불가, 인증, Relay, 요청 제한 오류를 사용자 문장으로 구분
- 일반 참가자는 `LeaveAsync`, 호스트는 `DeleteAsync`로 종료해 호스트 이전을 사용하지 않음
- 에디터 메뉴에서 실제 Relay 방 생성·삭제를 반복 검증할 수 있는 도구 제공

### 검증

- Unity 에디터 컴파일 및 씬 구성 검증 통과
- EditMode 자동 테스트 45개 통과
- 테스트 대상: Unity 버전, 렌더 파이프라인, 릴리스 씬, 입력 액션, 첫 플레이어블 씬 구성, 퓨즈 성공·실패·취소·중복 입력 방지, 소음 우선순위, 시야 각도·거리, 후각 반경, 시작 보호, 재물림 보호, 독성 단계 고정, 재감염 유지, 타이머 정지·만료, 해독제 사용·이동 취소·소지 한도
- 온라인 서비스 초기화→익명 인증 순서, 기존 로그인 재사용, 초기화 실패, Cloud 미연결, Bootstrap 씬 연결 테스트 통과
- 6명 비공개 방 생성, 참가 코드 정규화, 빈 코드 차단, 중복 요청 방지, 오류 메시지, 세션 종료 테스트 통과
- 메인 메뉴의 `NetworkManager`, `UnityTransport`, 세션 컨트롤러·화면 연결 테스트 통과
- 실제 재생에서 퓨즈 실패, 재시도, 성공과 플레이어 입력 잠금·복구 확인
- 실제 재생에서 퓨즈 실패 시 경로 거리 9.4m의 원숭이가 소음 조사 상태로 전환되는 것 확인
- 실제 재생에서 시야 감지 후 `Chase → Bite` 전환과 물기 1회 판정 확인
- 실제 재생에서 물기 성공 후 해당 표적을 즉시 재추격하지 않고 `Search`로 복귀하는 것 확인
- 소리 조사 중 일반 시야 대신 강화 단계 후각 반경의 근접 감지만 추격 전환에 사용하는 정책 확인
- 실험실 블록아웃의 빨간 원숭이 스폰 표시 구체 제거
- 실제 재생에서 괴물 물기 후 90초 감염과 HUD 표시 확인
- 실제 재생에서 테스트용 해독제 1개 주입 후 1.5초 사용·소비·치료 확인
- 30초 보호 해제 후에도 퓨즈 실패 `Medium` 소음 조사가 정상 동작하는 회귀 검사 통과
- 실제 재생에서 Cloud 미연결 시 메인 메뉴로 넘어가지 않고 연결 안내와 재시도 버튼을 표시하는 것 확인
- 실제 Unity Cloud 익명 인증과 Player ID 발급 후 메인 메뉴 전환 확인
- 실제 Relay Host 방 생성과 6자리 참가 코드 발급, `1/6`, 호스트 상태 확인
- 검증용 Relay 방을 호스트 삭제로 정상 정리

## 직접 실행 방법

1. 온라인 흐름은 Unity에서 `Assets/_Project/Scenes/00_Bootstrap.unity`를 열고 재생한다.
2. 메인 메뉴에서 `방 만들기` 또는 참가 코드 입력 후 `코드로 참가`를 누른다.
3. 로컬 게임플레이는 `Assets/_Project/Scenes/10_Laboratory.unity`를 열고 재생한다.
4. 화면 상단의 시작 보호 30초 동안 괴물이 순찰만 하는지 확인한다.
5. 보호 종료 후 `WASD`로 원숭이 시야에 들어가 밝은 빨간색 추격 상태를 확인한다.
6. 원숭이가 가까워지면 흰색 물기 상태와 피격 배너가 표시되고, 물기 성공 뒤 보라색 수색으로 복귀한다.
7. 물리면 우측 하단에 감염 타이머와 해독제 보유 상태가 표시된다.
8. 전력 복구실의 주황색 퓨즈 스테이션 가까이에서 `E`를 누른다.
9. 일부러 틀린 퓨즈를 눌러 소음 배너와 원숭이의 노란색 조사 상태를 확인한다. 조사 중에는
   현재 강화 단계의 후각 반경까지 가까워져야 밝은 빨간색 추격으로 바뀐다.
10. 원숭이는 소음 지점에서 보라색 탐색 상태를 거친 뒤 다시 순찰한다.
11. 해독 흐름은 새 재생에서 `Tools > Monkey Lab > Test Infection And Antidote`로 확인한다.
12. `Esc`로 미션을 취소하거나 `F`로 손전등을 켜고 끈다.
