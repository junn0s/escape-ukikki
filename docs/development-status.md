# 개발 현황

> 갱신일: 2026-07-29
> 기준 문서: `production-roadmap.md`, `game-design-document.md`, `technical-design-document.md`

이 문서는 기획 변경을 위한 문서가 아니라, 설계 문서가 Unity 프로젝트에 어디까지 반영됐는지 기록하는 작업 현황표다.

## 현재 단계

- M0 프로젝트 기반: 완료
- M1 로컬 버티컬 슬라이스: 진행 중
- M2 네트워크 기반 이후: 시작 전

## 이번 구현 완료

### 플레이어와 카메라

- `WASD` 이동
- 마우스 위치를 향한 캐릭터 회전
- 회전하지 않는 고정 쿼터뷰 추적 카메라
- `CharacterController` 기반 벽 충돌
- `F` 손전등 켜기·끄기

### 맵과 상호작용

- 연구소 10개 방 회색 박스 유지
- 각 방 외곽 벽과 통로 출입구 충돌 생성
- 6개 시작점 중 첫 번째 위치에 로컬 플레이어 배치
- 거리 기반 상호작용 대상 탐색
- 화면 하단 `E` 상호작용 안내
- 보안실 퓨즈 스테이션 배치
- 퓨즈 스테이션 상호작용 성공 상태 표시

### 검증

- Unity 에디터 컴파일 및 씬 구성 검증 통과
- EditMode 자동 테스트 5개 통과
- 테스트 대상: Unity 버전, 렌더 파이프라인, 릴리스 씬, 입력 액션, 첫 플레이어블 씬 구성

## 직접 실행 방법

1. Unity에서 `Assets/_Project/Scenes/10_Laboratory.unity`를 연다.
2. 상단 재생 버튼을 누른다.
3. `WASD`로 이동하고 마우스로 바라본다.
4. 보안실의 퓨즈 스테이션 가까이에서 `E`를 누른다.
5. `F`로 손전등을 켜거나 끈다.

## M1 다음 구현 순서

1. 퓨즈 순서 맞추기 미니게임과 실패 판정
2. 실패 시 중간 크기 소음 사건 발행
3. 괴물 한 마리 NavMesh 순찰과 소음 조사
4. 시야·후각 추격과 물기
5. 로컬 감염 타이머와 해독제
6. 한 명이 미션 실패부터 감염까지 경험하는 M1 전체 플레이 테스트

M1 완료 조건은 한 명이 이동해 미션을 실패하고, 소리를 조사하러 온 괴물을 피해 도망치며, 물리면 감염되는 흐름이 로컬에서 끊김 없이 작동하는 것이다.
