## 2026-07-30 — GDD 2.0: 3D 쿼터뷰 → 2D 탑다운 전환

- **핵심 규칙 변경.** 목표한 경험이 어몽어스 계열 2D 캐주얼이며 3D 쿼터뷰로는 그 톤이 나오지
  않는다고 판단해 표현 방식을 바꿨다. GDD 2.0으로 올리고 개정 이력을 문서에 남겼다.
  게임 규칙(역할·승패·루프·6인)은 1.0과 동일하다.
- **NavMesh를 그리드 A*로 대체.** NavMesh는 3D 전용이고 Unity에 2D 공식 내비게이션이 없다.
  외부 에셋 도입은 TDD §2.1 원칙에 걸려 자체 구현했다(셀 0.5m, 8방향, 옥타일 휴리스틱).
  경로 거리를 반환해야 GDD §11.2와 SDD §9.2의 "직선거리가 아닌 경로 거리" 규칙이 성립한다.
  대각선은 양쪽 직교 셀이 열려야 통과 — 안 그러면 괴물이 벽 모서리를 뚫는다.
- 문서 10개를 2D 기준으로 갱신(GDD·SDD·TDD·맵·아트·MVP·QA·밸런스·구조·README).
  캐릭터는 2등신으로 완화했다. 3등신 제약은 쿼터뷰에서 머리가 몸통을 가리는 문제였는데
  탑다운 정면 스프라이트에는 해당하지 않는다.
- 코드: Physics2D·Rigidbody2D 전환, `TopDownCamera`(직교) 신설, `GridPathAgent`·`PathGridBaker`
  추가, `QuarterViewCamera` 제거. 순수 로직(소음 우선순위·감염·퓨즈)은 수정 없이 재사용했다.
- 테스트 EditMode 47개 + PlayMode 3개 통과. PlayMode는 실제 씬에서 격자가 구워지고 맵 양 끝이
  연결되는지 검증한다(통행 2310셀 / 막힘 250셀).
- 다음 할 일: 에디터에서 2D 화면 확인, 이후 M2 네트워크 기반.
