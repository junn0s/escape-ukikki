# 해커톤 MVP 범위

> 문서 버전: 1.5
> 기준 GDD: 1.5
> 목표: 6명이 참가 코드로 접속해 한 판을 끝까지 플레이하고 핵심 재미를 평가할 수 있는 Windows 빌드

---

## 1. MVP의 검증 질문

MVP는 다음 질문에 답해야 한다.

1. 미션 실수로 발생한 소리가 괴물 추격의 원인으로 이해되는가?
2. 빌런이 직접 공격하지 않고도 스피커와 강화로 위험을 만들 수 있는가?
3. 생존자가 현장 흔적, CCTV와 로그, 행동 증언으로 빌런을 추리할 수 있는가?
4. 감염과 해독제 사전 제작이 협력과 의심을 동시에 만드는가?
5. 6명이 참가한 한 판이 오류 없이 승패까지 끝나는가?

이 질문에 직접 기여하지 않는 기능은 MVP에서 우선순위가 낮다.

## 2. 지원 환경

| 항목 | MVP 기준 |
| --- | --- |
| 플랫폼 | Windows 10/11 x64 |
| 화면 | 1920×1080 기준, 창 모드 지원 |
| 입력 | 키보드와 마우스 |
| 프레임 목표 | 기준 PC에서 60fps, 최저 30fps 이상 |
| 인원 | 6명 고정, 개발 모드에서 1~6명 |
| 연결 | 참가 코드 + Unity Relay |
| 서버 | 플레이어 한 명이 호스트 |
| 언어 | 한국어 |
| 음성 채팅 | 지원하지 않음 |

## 3. 필수 플레이 기능

### 3.1 세션과 로비

- 익명 로그인
- 세션 생성
- 6자리 또는 서비스가 제공하는 참가 코드 표시
- 코드로 참가
- 닉네임과 플레이어 색상
- 준비 상태
- 6명 모두 준비 시 시작
- 개발 모드 인원 제한 해제

### 3.2 라운드

- 역할 무작위 배정
- 개인 역할 공개
- 시작 보호 시간 30초
- 탐색 타이머 15분
- 회의 중 월드 및 타이머 정지
- 서버 권한 승패 판정
- 결과 화면과 로비 복귀

### 3.3 플레이어

- WASD 이동
- 마우스 방향 보기
- 직교 투영 2D 탑다운 카메라
- 손전등
- 상호작용 감지와 프롬프트
- 플레이어 색상·닉네임 표시
- 감염, 사망, 유령 상태

### 3.4 맵

- 10개 방과 복도 전체 그레이박스
- 방 이름 표지
- 최소 두 개의 순환 경로
- 플레이어 시작 지점 6개
- 괴물 시작 지점 4개
- 격리실 추가 괴물 지점 4개
- 스피커, CCTV, 단말기, 미션 스테이션 배치

### 3.5 괴물

- 2D 웨이포인트 그래프 순찰
- 방 체류 약 6초
- 소리 조사
- 방향 없는 원형 근접 감지. 손전등과 이동 여부는 감지 조건이 아니다
- 미션 실패·스피커 등 소음 현장 급습으로 괴물을 그 방으로 유인
- 6초 가속
- 물기와 감염
- 4→6→8마리 증가
- 문과 좁은 복도에서 기본 회피

### 3.6 미션

핵심 4종을 기반으로 실제 조작 방식이 겹치지 않는 아래 9종을 회색상자 수준으로 완성한다.

1. 퓨즈 순서 맞추기
2. 차단기 타이밍
3. CCTV 재부팅
4. 시료 분류
5. 비상 배터리 운반
6. 압력 밸브 안정화
7. 출입문 보안 회로
8. 구조 안테나 조율
9. 서버 로그 복구

10개 방에는 9종을 분산하고 시료 분류만 두 위치에서 서로 다른 시드로 제공한다.

### 3.7 빌런

- 실제 9종 조작을 수행하지만 진행률을 올리지 않는 가짜 미션 목록과 정상 수행 연출
- 드래그 혼합·클릭 회로·타이밍 주입으로 구성된 빌런 강화 미션 3종
- 후각 강화 2회
- 괴물 수 증가 2회
- 독성 강화 2회
- 방 스피커 원격 작동
- 45초 쿨타임
- 3종 현장 흔적과 스피커 흔적

### 3.8 감염과 해독제

- 90/60/30초 감염 타이머
- 감염 중 이동 속도 감소
- 백신실 중앙 제어 PC 2대, 5자리 배합 코드 발급
- 백신실 제작대 2대, 코드 입력과 합성
- 오입 3회 시 코드 무효화
- 완성품 선점
- 소지 한도 1개
- 1.5초 해독제 사용

### 3.9 회의와 투표

- 살아 있는 플레이어의 호출
- 첫 2분 제한과 공용 2분 쿨타임
- 최대 3회
- 텍스트 토론 90초
- 투표 30초
- 기권, 동률, 단독 최다 처리
- 생존자 퇴출 시 유령 전환
- 빌런 퇴출 시 즉시 승리

### 3.10 정보

- 프로젝트 단계에 따른 조명 변화
- 50% 이후 CCTV 채널
- 전자지도와 방 이름
- 서버 출입·시설 로그
- 영구 현장 단서
- 결과 타임라인

## 4. MVP 에셋 범위

### 4.1 반드시 제작 또는 확보

- 직원 기본 스프라이트 세트 1개와 색상 6종
- 원숭이 괴물 스프라이트 세트 1개
- 플레이어 필수 4방향 또는 8방향 애니메이션 8종 이상
- 괴물 필수 4방향 또는 8방향 애니메이션 7종 이상
- 모듈형 연구소 벽 단면·바닥·문 스프라이트
- 방별 핵심 상호작용 오브젝트
- 손전등, 연기, 전기, 감염, 가스 VFX
- 필수 UI 아이콘과 화면
- 정보성 효과음과 기본 배경음

### 4.2 임시 에셋 허용

- 헬기 모델과 엔딩 배경
- 장식용 소품
- 캐릭터 얼굴과 헤어 변형
- 고유 미션 애니메이션
- 고품질 시네마틱

외부 에셋은 라이선스와 출처를 `THIRD_PARTY_NOTICES.md`에 기록한다.

## 6. 개발용 데모 모드

6명을 항상 모을 수 없으므로 개발 빌드에 다음 기능을 제공한다.

- 1~6명으로 강제 시작
- 역할 강제 지정
- 시작 보호 시간 건너뛰기
- 프로젝트 게이지 단계 변경
- 괴물 수와 강화 단계 변경
- 플레이어 감염·치료·사망
- 해독제 즉시 제작
- 회의 쿨타임 초기화
- 라운드 남은 시간 변경
- 승패 조건 강제 실행
- 괴물 AI 상태와 현재 목표 표시
- 소음 반경 시각화

개발 기능은 릴리스 빌드에서 컴파일 플래그 또는 설정으로 비활성화한다.

## 7. 기능별 완료 정의

### 네트워크 완료

- 서로 다른 두 PC에서 참가 코드로 접속된다.
- 6명 상태와 준비 상태가 일치한다.
- 역할이 자기 클라이언트에만 공개된다.
- 100ms 지연 환경에서 이동과 상호작용이 중복되지 않는다.

### 괴물 완료

- 네트워크 전체에서 같은 목표를 추적한다.
- 가장 가까운 유효 소음을 선택한다.
- 감지 반경 안에 들어간 플레이어는 손전등을 끄거나 멈춰도 추격당한다. 반경 밖으로 벗어나야 끊긴다.
- 문에 끼거나 영구 정지하지 않는다.
- 물기와 감염 결과가 모든 클라이언트에서 일치한다.

### 미션 완료

- 소유자만 시작할 수 있다.
- 성공은 한 번만 반영된다.
- 실패 소음이 한 번만 생성된다.
- 연결 지연이나 중복 입력으로 진행률이 두 번 오르지 않는다.

### 회의 완료

- 월드 상태가 완전히 정지한다.
- 참가자와 표 수가 일치한다.
- 동률, 기권, 시간 초과가 정의대로 처리된다.
- 회의 종료 후 괴물과 타이머가 정상 재개된다.

### 라운드 완료

- 모든 승패 조건이 서버에서 한 번만 확정된다.
- 결과 화면의 역할과 사건 기록이 실제 라운드와 일치한다.
- 다시 로비로 돌아가 다음 판을 시작할 수 있다.

## 8. 전체 MVP 완료 조건

- 6명이 참가 코드로 연결된다.
- 한 판을 시작해 15분 또는 조기 승리로 끝낼 수 있다.
- 생존자와 빌런 양쪽 모두 실제로 승리할 수 있다.
- 소음, 괴물, 강화, 단서, 회의의 핵심 연결이 플레이 중 발생한다.
- 치명적 오류 없이 연속 3판을 완료한다.
- 기준 PC에서 평균 60fps, 최저 30fps 이상을 유지한다.
- 호스트 이외 클라이언트에서 역할·미션 정보가 잘못 노출되지 않는다.
- 심사용 Windows 빌드와 2~3분 데모 영상이 준비된다.

---

## 9. 일정 부족 시 제거 순서

핵심 루프를 보존하기 위해 다음 순서로 줄인다.

1. 엔딩 헬기 상세 연출
2. 장식용 환경 에셋과 캐릭터 변형
3. 실시간 CCTV를 최근 캡처 또는 이동 로그로 대체
4. 전자지도의 상세 기능
5. 백신실 PC·제작대 사이 차폐 프롭 연출
6. 생존자 미션 종류를 4종에서 3종으로 축소
7. 결과 화면 상세 통계

다음 기능은 제거하지 않는다.

- 네트워크 한 판 완주
- 소음과 괴물 추적
- 빌런의 스피커 또는 강화 중 최소 하나
- 현장 단서
- 회의와 투표
- 승패 판정
