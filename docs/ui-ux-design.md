# UI·UX 설계서

> 문서 버전: 1.9
> 기준 해상도: 1920×1080  
> 입력: 키보드·마우스

---

## 1. UX 목표

- 플레이어는 5초 안에 현재 목표와 위험을 이해한다.
- 역할 비밀 정보가 다른 클라이언트에 노출되지 않는다.
- 어두운 화면에서도 상호작용 대상과 단서를 찾을 수 있다.
- 소음과 괴물 반응의 인과관계가 시각·청각으로 전달된다.
- 회의에서는 시간, 발언자, 투표 상태를 한 화면에서 본다.
- 색상에 의존하지 않고 아이콘, 번호, 형태를 함께 쓴다.

---

## 2. 전체 화면 흐름

```text
Boot
→ 타이틀
→ 배경 이야기 (첫 실행 1회, 언제든 건너뛰기)
→ 메인 메뉴
  ├─ 방 만들기
  ├─ 코드로 참가
  ├─ 이야기 다시 보기
  ├─ 설정
  └─ 종료
→ 로비
→ 로딩
→ 역할 공개
→ 인게임
  ↔ 회의/투표
→ 결과
→ 로비 또는 메인 메뉴
```

---

## 2.1 배경 이야기 화면

플레이어가 자기 역할을 이해하려면 먼저 이 연구소에서 무슨 일이 있었는지 알아야 한다.
빌런이 "괴물을 만든 해고된 과학자"라는 설정을 모르면 역할 공개 화면의 `당신은 빌런입니다`가
아무 의미도 전달하지 못한다.

**표시 시점**

- 메인 메뉴에 처음 들어올 때 1회 자동 재생한다.
- 이후에는 메인 메뉴의 `이야기` 버튼으로 다시 볼 수 있다.
- 라운드 시작마다 반복하지 않는다. 6명이 매번 같이 기다리게 되고 연속 3판 완주
  (mvp-scope 8장)를 방해한다.

**내용**

`game-design-document.md` §4 세계관을 그대로 쓴다. 이 화면은 새 설정을 만들지 않는다.

| 장 | 출처 | 담을 것 |
| --- | --- | --- |
| 1 | GDD §4.1 | 한도윤 박사의 해고와 RX-9 가스 개조 |
| 2 | GDD §4.1 | RX-9이 공격성과 후각을 증폭해 실험 원숭이를 괴물로 만듦 |
| 3 | GDD §4.2 | 정전, 괴물 4마리 방생, 봉쇄된 비상문 |
| 4 | GDD §4.2 | 야근 중이던 6명 안에 박사가 섞여 있음 |
| 5 | GDD §4.2 | 15분 뒤 출입구 RX-9 가스 살포 |

**조작**

- 아무 키나 클릭으로 다음 장. 마지막 장 다음은 메인 메뉴.
- `Esc` 또는 `건너뛰기` 버튼으로 언제든 종료한다. **건너뛰기는 항상 화면에 보여야 한다.**
- 자동 넘김을 두지 않는다. 읽는 속도는 사람마다 다르다.

**저장**

- 재생 여부만 로컬에 남긴다(`PlayerPrefs`). 서버 판정과 무관하다.
- 설정 초기화로 다시 첫 실행 상태가 된다.

## 3. 메인 메뉴

필수 구성:

- 게임 로고와 버전
- 방 만들기
- 코드로 참가
- 이야기 (배경 이야기 다시 보기, §2.1)
- 설정
- 게임 종료
- 네트워크 서비스 상태

코드 참가를 누르면 닉네임, 참가 코드와 확인 버튼을 보여준다. 오류는 기술 코드만 표시하지 말고 “코드가 만료됐습니다”, “세션 인원이 가득 찼습니다”처럼 해결 가능한 문장으로 표시한다.

## 4. 로비

```text
┌────────────────────────────────────────────────────┐
│ 참가 코드: A1B2C3                   [코드 복사]     │
├────────────────────────────────────────────────────┤
│ 1. 파랑  Junsu       준비                          │
│ 2. 노랑  Player2     준비                          │
│ 3. 초록  Player3     대기                          │
│ 4. 빨강  Player4     준비                          │
│ 5. 보라  Player5     준비                          │
│ 6. 주황  Player6     준비                          │
├────────────────────────────────────────────────────┤
│ [색상 선택] [준비 완료]                [시작!: Host]│
└────────────────────────────────────────────────────┘
```

- 동일 색상 선택은 서버가 거부한다.
- 호스트 표시와 연결 품질 아이콘을 제공한다.
- 일반 플레이에서는 6명 전원 준비가 필요하다.
- 개발 빌드에는 강제 시작 버튼을 별도로 둔다.

## 5. 역할 공개

### 생존자

- 큰 역할명: `생존자`
- 목표 세 줄: 미션 100%, 빌런 퇴출, 해독제 준비
- 개인 색상과 첫 미션 구역
- 5초 후 자동 닫힘, 클릭으로 최소 2초 이후 건너뛰기

### 빌런

- 큰 역할명: `빌런 — 한도윤 박사`
- 목표: 프로젝트 방해, 생존자 제거, 정체 은폐
- 강화 세 축 아이콘
- 스피커 리모컨 키 안내

역할 화면은 스크린숏 공유 위험을 줄일 수 없으므로 외부 스트리밍 보호는 MVP 범위에 포함하지 않는다.

## 6. 인게임 HUD

```text
┌──────────────────────────────────────────────────────────┐
│ 14:32        프로젝트 █████░░░░░ 42%       회의 0/3     │
│                                                          │
│ [미션 목록]                           [현재 방: 보안실]   │
│ □ 퓨즈 교체                                             │
│ ■ CCTV 재부팅                                           │
│ □ 시료 분류                                             │
│                                                          │
│                    게임 월드                             │
│                                                          │
│                                            [감염 00:47]  │
│                                            [해독제 1/1]  │
│ [Tab 지도] [F 손전등]            [E 상호작용] [R 사용] │
└──────────────────────────────────────────────────────────┘
```

0% 단계의 월드 지형은 4% 전역광이 만드는 벽 윤곽 실루엣과 손전등 원뿔 안에서만 보인다.
전역광 4%로는 방향과 통로 모서리만 분간되고 바닥색·표지·프롭·미션 스테이션은 식별되지
않으므로, 실제 탐색은 계속 손전등에 의존한다. `F`로 소등하면 캐릭터 실루엣을 위한
0.5m의 0.6% 개인등만 남는다. 손전등은 감지에 영향을 주지 않으므로 켜 두는 것이 손해가
아니다(GDD 1.6). 괴물을 피하는 유일한 방법은 감지 반경 밖으로 거리를 두는 것이다.

### 6.1 항상 표시

- 탐색 남은 시간
- 프로젝트 진행률
- 현재 방 이름
- 상호작용 프롬프트
- 회의 사용 횟수와 쿨타임

### 6.2 상황별 표시

- 미션 목록: 좌측, 접기 가능
- 해독제 슬롯: 보유 시
- 감염 타이머: 감염 시 매우 명확하게
- 배터리 운반 상태
- 스피커 쿨타임과 강화 단계: 빌런에게만
- 유령 상태와 남은 미션: 유령에게만

### 6.3 상호작용 프롬프트

```text
[E] CCTV 재부팅
사용 중: 파랑
```

접근 불가 이유를 짧게 표시한다.

- 레시피가 필요합니다.
- 다른 플레이어가 사용 중입니다.
- 살아 있는 플레이어만 사용할 수 있습니다.
- 프로젝트 50%에서 활성화됩니다.

### 6.4 빌런 강화 미션

- 후각: 두 혼합 밸브를 가로 슬라이더로 드래그하고 압력 안정화 바가 찬 뒤 `혼합물 봉인`
- 개체: 세 회로 모듈을 클릭 회전하고 현재 방향과 목표 방향을 비교한 뒤 `시험 가동`
- 독성: 왕복 주입 마커가 단계별 안전 구간에 들어왔을 때 `Space` 또는 `주입`
- 완료 여부를 미리 확정하지 않고 `서버 확인 중` 상태를 거쳐 강화 결과를 표시한다.
- 빌런 본인에게만 퍼즐 내용을 표시하며, 월드 캐릭터의 수행 애니메이션은 정상 미션과 같다.

### 6.5 통합 게임 피드백

- 우측 상단에 현재 방 또는 `연구소 복도`를 항상 표시하고 구역 전환 시 짧은 진입 배너를 낸다.
- 마우스 위치에는 에셋 없는 절차형 조준점을 표시하고, 상호작용 대상에는 네 모서리 표식을 붙인다.
- 미션 시작·실패·취소·완료와 25/50/75/100% 단계는 같은 상단 사건 배너 규칙으로 전달한다.
- 서버가 자신을 추적 대상으로 판정한 동안만 붉은 화면 가장자리를 맥동시키며 방향·거리는 숨긴다.
- 물림은 짧은 붉은 플래시와 위치 흔들림으로 표현하고 카메라는 회전하지 않는다.
- 하단 조작 도움말은 미션·감염·상호작용 UI를 가리지 않는 한 줄 높이로 유지한다.

### 6.6 개발 데모 패널

- 호스트의 에디터·Development 빌드에서만 `F10`으로 연다.
- 라운드 단계·프로젝트 0/25/50/75/100%·남은 시간·강제 승패를 한 구역에서 조작한다.
- 연결 플레이어를 번호로 선택해 역할, 건강·감염·유령, 해독제 지급을 조작한다.
- 후각·개체·독성 0~2단계와 현재 괴물별 상태·목표 client ID를 표시한다.
- 마지막 소음의 종류·방·경로 반경을 표시하고 월드 반경 원을 켜고 끌 수 있다.
- 일반 HUD와 혼동하지 않도록 우측 독립 패널로 두고 Release 빌드에서는 생성하지 않는다.

## 7. 프로젝트 단계 피드백

각 단계 도달 시 화면 상단에 3초 배너를 표시한다.

| 단계 | 배너 |
| ---: | --- |
| 25% | `부분 전력 복구 — 일부 조명이 켜졌습니다.` |
| 50% | `보안망 복구 — CCTV와 전자지도가 활성화됩니다.` |
| 75% | `탈출 경로 확인 — 출구와 남은 미션 구역이 표시됩니다.` |
| 100% | `시설 복구 완료 — 생존자 승리` |

배너가 괴물, 감염 타이머와 상호작용 프롬프트를 가리지 않도록 상단 중앙에 제한한다.

## 8. 전자지도

### 0~49%

- 발견한 방 이름과 자기 미션 아이콘
- 플레이어 현재 위치
- 다른 플레이어 위치는 표시하지 않음

### 50~74%

- 모든 방 이름
- CCTV 위치와 활성 상태
- 로그 단말기
- 자기 미션과 백신실

### 75~99%

- 탈출구 위치
- 미완료 미션이 있는 구역 표시
- 빌런의 정확한 강화 위치는 표시하지 않음

빌런은 지도에서 스피커 사용 모드로 전환할 수 있다. 사용 가능한 방, 쿨타임과 마지막 선택만 보이며 다른 플레이어 위치는 제공하지 않는다.

## 9. 미션 UI

### 9.1 공통 프레임

- 제목
- 짧은 한 줄 목표
- 조작 영역
- 성공·실패 상태
- 나가기 버튼 또는 `Esc`
- 화면 가장자리의 위험 경고

미션 중 월드가 멈추지 않으므로 UI는 화면 전체를 완전히 가리지 않는다. 가장자리에서 붉은 괴물 접근 경고를 제한적으로 제공하되 정확한 방향과 거리를 알려주지는 않는다.
경고는 서버가 해당 플레이어를 실제 추적·물기 대상으로 판정한 동안에만 맥동하며,
성공은 초록 가장자리 확산, 실패는 붉은 흔들림과 스테이션 점멸로 즉시 구분한다.

### 9.2 퓨즈

- 좌측에 퓨즈 3~5개
- 우측에 색상과 번호가 있는 슬롯
- 퓨즈를 직접 잡아 현재 활성 슬롯까지 드래그해 삽입
- 잘못 삽입하면 즉시 실패 소음

### 9.3 차단기

- 이동하는 표시선과 목표 영역
- 표시선이 목표 영역에 들어오는 순간 차단기 버튼을 클릭하거나 `Space` 입력
- 타이밍 실패 시 스파크와 소음

### 9.4 CCTV 재부팅

- 왼쪽 신호 노드를 클릭해 선택한 뒤 같은 문자·색상의 오른쪽 포트를 클릭해 3개 채널 연결
- 선택된 노드에서 포인터까지 케이블 미리보기를 표시
- 실패해도 큰 소음 대신 시간 손실 위주

### 9.5 시료 분류

- 시료를 클릭해 분석 대상으로 선택한 뒤 라벨 문자·색상과 일치하는 보관함을 클릭
- 제한시간은 없지만 잘못 분류하면 중간 소음

### 9.6 비상 배터리 운반

- 시작 단말기에서 배터리를 잡아 분리 레일 끝까지 드래그
- 분리되면 미션 화면이 닫히고 운반 HUD와 이동 속도 감소가 적용
- 연결된 수신 단말기 앞에서 `E`를 눌러 장착 화면을 다시 열고 배터리를 소켓에 드롭
- 운반 중 `Esc`로 놓으면 낙하 실패와 중간 소음 발생

### 9.7 압력 밸브

- 좌우 밸브 손잡이를 원형으로 직접 돌려 개방도를 조절
- 두 개방도의 결과를 중앙 압력계에서 실시간 확인
- 압력을 초록 안전 구간에 유지해 안정화 게이지를 채운 뒤 잠금 레버를 끝까지 내림
- 안정화 전에 잠그면 압력 실패와 중간 소음 발생

### 9.8 출입문 보안 회로

- 3~5개 회로 모듈을 클릭할 때마다 90도 회전
- 각 모듈의 현재 방향과 목표 방향을 맞춘 뒤 `Space` 또는 전원 인가 버튼으로 검증
- 정렬되지 않은 상태에서 전원을 넣으면 합선과 중간 소음 발생

### 9.9 구조 안테나 조율

- 격자 안의 현재 신호점을 `WASD` 또는 방향키로 한 칸씩 이동
- 방위와 주파수를 동시에 나타내는 목표 셀에 맞춘 뒤 `Enter`로 구조 신호 고정
- 마우스 방향 버튼도 제공하되 모든 이동 입력은 서버가 한 칸씩 재현
- 다른 셀에서 신호를 고정하면 송신 실패와 중간 소음 발생

### 9.10 서버 로그 복구

- 손상 로그 조각마다 `Q`, `W`, `E`, `R`, `T` 키캡을 표시
- 왼쪽부터 키보드로 직접 입력하며, 마우스 키캡 클릭도 지원
- 오타가 발생하면 복구 세션이 초기화되고 경고음 발생

### 9.11 빌런 가짜 UI

외부에서 관찰할 때 정상 미션과 같은 시간과 애니메이션을 사용한다. 빌런 본인에게는 UI 안쪽에 작게 실제 강화 축과 결과를 표시한다.

설정 화면은 메인 메뉴와 라운드에서 `F1` 또는 우하단 `설정` 버튼으로 연다.
온라인 라운드는 설정 화면을 열어도 일시정지되지 않으며 `F1` 또는 `Esc`로 닫는다.
설정값은 로컬에 즉시 저장되어 다음 실행에도 유지된다.

- 밝기는 65~100% 범위에서 화면을 더 어둡게 조절한다. 암흑 시야 규칙을 무력화하는
  기본값 이상의 증폭은 제공하지 않는다.
- 화면 흔들림, 플래시·점멸, 위험 비네팅은 0~100%로 각각 조절한다.
- 소리 자막과 8방향 화살표는 독립적으로 켜고 끈다.
- 색상 구분 보조는 기본, 녹색약, 적색약, 청색약, 고대비 프리셋을 순환한다.
  성공·경고·위험은 프리셋과 관계없이 기호와 문장을 함께 표시한다.
- 마스터·음악·효과음·UI·괴물/위험 음량은 별도 로컬 채널로 저장한다.

## 15. UI 시각 규칙

### 15.1 의미 색상

- 일반 생존자 정보: 청록·백색
- 경고: 주황
- 즉시 위험·감염: 적색
- 빌런 전용 정보: 자주색과 적색 조합
- 유령: 청회색
- 성공: 녹색만 쓰지 않고 체크 아이콘 병행
- 실패: 적색만 쓰지 않고 X 아이콘과 문장 병행

색상 값은 `art-audio-asset-guide.md` §1.3 팔레트를 그대로 쓴다. UI가 독자 팔레트를 만들지 않는다.

### 15.2 타이포그래피

1920×1080 기준 크기이며, 설정의 텍스트 크기(85~140%)를 곱해 적용한다.

| 용도 | 크기 | 굵기 |
| --- | ---: | --- |
| 화면 제목 (역할 공개, 결과) | 56 | Bold |
| 구역 제목 (패널 헤더, 미션 제목) | 32 | Bold |
| 강조 수치 (감염 타이머, 남은 시간) | 32 | Bold |
| 사건 배너 | 40 | Bold |
| 본문·버튼 라벨·목록 | 24 | Bold |
| 보조 설명·조작 힌트 | 20 | Regular |

- **18px 미만은 쓰지 않는다.** 1280×720에서 읽을 수 없다.
- 모든 텍스트에 검정 외곽선을 넣어 어두운 월드와 밝은 손전등 원뿔 위에서 같은
  가독성을 유지한다. 반투명 패널이 없는 위치(이름표, 월드 프롬프트)에서는 필수다.
- 본문은 한글 산세리프 Bold를 기본으로 쓴다. Regular는 보조 설명에만 쓴다.
- 장식용 글꼴은 로고에만 쓴다.
- 시스템 폰트에 의존하지 않는다. 폰트 에셋을 저장소에 포함해 모든 PC에서 같은
  글자가 나오게 한다.

확정 서체는 다음과 같다. 파일과 라이선스 요약은 `Assets/_Project/Art/Fonts/`에 있다.

| 용도 | 서체 | TMP 에셋 |
| --- | --- | --- |
| 본문·버튼·제목 | 에스코어 드림 6 Bold | `SCDream_Bold SDF` |
| 보조 설명 | 에스코어 드림 4 Regular | `SCDream_Regular SDF` |
| 로고 전용 | 배달의민족 을지로체 | `Euljiro_Display SDF` |

한글은 완성형만 11,172자라 아틀라스에 전부 미리 굽지 않는다. TMP 에셋은
Dynamic 모드로 만들어 실제로 쓰인 글자만 실행 중에 올린다.
`Tools > Monkey Lab > Build > Create Or Update UI Theme` 하나로 TMP 에셋 생성과
테마 연결이 끝나므로 Font Asset Creator를 손으로 돌리지 않는다.

### 15.3 형태

- 패널: 모서리 반경 20px, 어두운 불투명 배경, 1~2px 밝은 테두리
- 버튼: 모서리 반경 16px, 최소 높이 56px, 채도 높은 단색 면, 아래쪽에 어두운
  립을 두어 두께감을 준다. 눌림 상태는 립을 줄여 내려앉는 느낌으로 표현한다
- 아이콘·체크·X는 면으로 채운 굵은 형태를 쓰고 얇은 선 아이콘은 쓰지 않는다
- 정보는 색만으로 구분하지 않고 번호·기호·문장을 항상 병행한다

이 형태 문법은 카툰 소셜 디덕션 게임의 가독성 관행을 따른 것이다. 형태 문법만
가져오고 캐릭터·방·아이콘·로고는 `art-audio-asset-guide.md` §1.1대로 RX-9 고유
디자인을 유지한다.

### 15.4 구현 스택

- uGUI + TextMeshPro로 구현한다. 외곽선·둥근 모서리·텍스트 크기 배율을 IMGUI로는
  일관되게 만들 수 없다.
- 색·크기·모서리 반경·폰트 에셋은 `Assets/_Project/Data/UI/SO_UiTheme_Default.asset`
  하나에 모으고 화면마다 값을 다시 적지 않는다.
- 단 §15.1 의미 색상과 텍스트 크기 배율은 테마에 넣지 않는다. 색각 보정 프리셋과
  설정값을 거쳐야 하므로 `LocalGameSettings.GetSemanticColor`와
  `GetScaledFontSize`가 계속 담당한다. 테마는 패널·글자·외곽선 같은 고정 크롬만 갖는다.
- 화면 프리팹은 `P_UI_` 접두사를 쓰고 편집기 빌더로 생성한다.
- 폰트 에셋이 붙지 않은 상태에서는 화면 프리팹을 생성하지 않는다. 빌더가 먼저 막는다.

### 15.5 문구 톤

카툰 소셜 디덕션 게임의 짧고 단정한 어법을 쓴다. 형태 문법과 같은 이유로,
읽는 데 시간이 걸리면 5초 안에 상황을 파악할 수 없다.

- 버튼 라벨은 2~6자. 한 줄을 넘기지 않는다
- 명사형 또는 명령형을 쓴다. `~하고 있습니다` 같은 설명체를 버튼과 상태줄에 쓰지 않고
  `~ 중`으로 줄인다
- 기술 용어를 화면에 노출하지 않는다. `Relay`, `세션`, `동기화`, `클라이언트`는
  `방`, `연결`, `참가자`로 바꿔 쓴다
- 감탄사는 시작·성공·승리에만 쓰고 한 화면에 하나까지만 둔다
- **반말을 쓰지 않는다.** 짧은 명사형으로 적어 존대와 반말 구분이 생기지 않게 한다.
  화면마다 말투가 달라지는 것을 막는다

다음은 톤을 줄이지 않는다. 짧게 만들려다 정보를 지우면 안 되는 문구다.

- 오류 문구: §3 규칙대로 해결 방법을 담은 문장을 유지한다
- 위험·감염·사망·괴물 문구: 긴장을 전달해야 하므로 장난스럽게 쓰지 않고
  짧고 단호하게 쓴다
- 접근 불가 이유: §6.3 규칙대로 이유를 남긴다

| 이전 | 이후 |
| --- | --- |
| `게임 시작` | `시작!` |
| `준비 해제` | `준비 취소` |
| `세션 나가기` | `방 나가기` |
| `Relay 방을 만들고 있습니다...` | `방 만드는 중` |
| `로비 참가자 상태를 동기화하고 있습니다...` | `참가자 불러오는 중` |
| `6명이 참가 코드를 공유해 같은 방에 접속합니다.` | `코드를 공유해 6명을 모으세요` |

## 17. UX 완료 기준

- 처음 플레이한 사람이 별도 설명 없이 이동과 첫 미션을 시작할 수 있다.
- 감염된 플레이어가 3초 안에 남은 시간과 해독제 보유 여부를 파악한다.
- 빌런 UI가 생존자 클라이언트에 보이지 않는다.
- 프로젝트 단계 변화가 소리 없이도 인지된다.
- 회의에서 남은 시간, 참가자와 자기 투표 상태가 항상 보인다.
- 1280×720에서도 필수 정보가 겹치지 않는다.
- 색상을 구분하지 못해도 아이콘과 번호로 플레이 가능하다.
