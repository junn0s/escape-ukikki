# UI·UX 설계서

> 문서 버전: 1.0  
> 기준 해상도: 1920×1080  
> 입력: 키보드·마우스

---

## 1. UX 목표

- 플레이어는 5초 안에 현재 목표와 위험을 이해한다.
- 역할 비밀 정보가 다른 클라이언트에 노출되지 않는다.
- 어두운 화면에서도 상호작용 대상과 단서를 찾을 수 있다.
- 소음과 괴물 반응의 인과관계가 시각·청각으로 전달된다.
- 회의에서는 시간, 발언자, 투표 상태를 한 화면에서 본다.
- 색상에 의존하지 않고 아이콘, 번호, 형태를 함께 쓴다.

---

## 2. 전체 화면 흐름

```text
Boot
→ 타이틀
→ 메인 메뉴
  ├─ 방 만들기
  ├─ 코드로 참가
  ├─ 설정
  └─ 종료
→ 로비
→ 로딩
→ 역할 공개
→ 인게임
  ↔ 회의/투표
→ 결과
→ 로비 또는 메인 메뉴
```

---

## 3. 메인 메뉴

필수 구성:

- 게임 로고와 버전
- 방 만들기
- 코드로 참가
- 설정
- 게임 종료
- 네트워크 서비스 상태

코드 참가를 누르면 닉네임, 참가 코드와 확인 버튼을 보여준다. 오류는 기술 코드만 표시하지 말고 “코드가 만료됐습니다”, “세션 인원이 가득 찼습니다”처럼 해결 가능한 문장으로 표시한다.

## 4. 로비

```text
┌────────────────────────────────────────────────────┐
│ 참가 코드: A1B2C3                   [코드 복사]     │
├────────────────────────────────────────────────────┤
│ 1. 파랑  Junsu       준비                          │
│ 2. 노랑  Player2     준비                          │
│ 3. 초록  Player3     대기                          │
│ 4. 빨강  Player4     준비                          │
│ 5. 보라  Player5     준비                          │
│ 6. 주황  Player6     준비                          │
├────────────────────────────────────────────────────┤
│ [색상 선택] [준비/해제]            [게임 시작: Host]│
└────────────────────────────────────────────────────┘
```

- 동일 색상 선택은 서버가 거부한다.
- 호스트 표시와 연결 품질 아이콘을 제공한다.
- 일반 플레이에서는 6명 전원 준비가 필요하다.
- 개발 빌드에는 강제 시작 버튼을 별도로 둔다.

## 5. 역할 공개

### 생존자

- 큰 역할명: `생존자`
- 목표 세 줄: 미션 100%, 빌런 퇴출, 해독제 준비
- 개인 색상과 첫 미션 구역
- 5초 후 자동 닫힘, 클릭으로 최소 2초 이후 건너뛰기

### 빌런

- 큰 역할명: `빌런 — 한도윤 박사`
- 목표: 프로젝트 방해, 생존자 제거, 정체 은폐
- 강화 세 축 아이콘
- 스피커 리모컨 키 안내

역할 화면은 스크린숏 공유 위험을 줄일 수 없으므로 외부 스트리밍 보호는 MVP 범위에 포함하지 않는다.

## 6. 인게임 HUD

```text
┌──────────────────────────────────────────────────────────┐
│ 14:32        프로젝트 █████░░░░░ 42%       회의 0/3     │
│                                                          │
│ [미션 목록]                           [현재 방: 보안실]   │
│ □ 퓨즈 교체                                             │
│ ■ CCTV 재부팅                                           │
│ □ 시료 분류                                             │
│                                                          │
│                    게임 월드                             │
│                                                          │
│                                            [감염 00:47]  │
│                                            [해독제 1/1]  │
│ [Tab 지도] [F 손전등]            [E 상호작용] [R 사용] │
└──────────────────────────────────────────────────────────┘
```

### 6.1 항상 표시

- 탐색 남은 시간
- 프로젝트 진행률
- 현재 방 이름
- 상호작용 프롬프트
- 회의 사용 횟수와 쿨타임

### 6.2 상황별 표시

- 미션 목록: 좌측, 접기 가능
- 해독제 슬롯: 보유 시
- 감염 타이머: 감염 시 매우 명확하게
- 배터리 운반 상태
- 스피커 쿨타임과 강화 단계: 빌런에게만
- 유령 상태와 남은 미션: 유령에게만

### 6.3 상호작용 프롬프트

```text
[E] CCTV 재부팅
사용 중: 파랑
```

접근 불가 이유를 짧게 표시한다.

- 레시피가 필요합니다.
- 다른 플레이어가 사용 중입니다.
- 살아 있는 플레이어만 사용할 수 있습니다.
- 프로젝트 50%에서 활성화됩니다.

## 7. 프로젝트 단계 피드백

각 단계 도달 시 화면 상단에 3초 배너를 표시한다.

| 단계 | 배너 |
| ---: | --- |
| 25% | `부분 전력 복구 — 일부 조명이 켜졌습니다.` |
| 50% | `보안망 복구 — CCTV와 전자지도가 활성화됩니다.` |
| 75% | `탈출 경로 확인 — 출구와 남은 미션 구역이 표시됩니다.` |
| 100% | `시설 복구 완료 — 생존자 승리` |

배너가 괴물, 감염 타이머와 상호작용 프롬프트를 가리지 않도록 상단 중앙에 제한한다.

---

## 8. 전자지도

### 0~49%

- 발견한 방 이름과 자기 미션 아이콘
- 플레이어 현재 위치
- 다른 플레이어 위치는 표시하지 않음

### 50~74%

- 모든 방 이름
- CCTV 위치와 활성 상태
- 로그 단말기
- 자기 미션과 백신실

### 75~99%

- 탈출구 위치
- 미완료 미션이 있는 구역 표시
- 빌런의 정확한 강화 위치는 표시하지 않음

빌런은 지도에서 스피커 사용 모드로 전환할 수 있다. 사용 가능한 방, 쿨타임과 마지막 선택만 보이며 다른 플레이어 위치는 제공하지 않는다.

## 9. 미션 UI

### 9.1 공통 프레임

- 제목
- 짧은 한 줄 목표
- 조작 영역
- 성공·실패 상태
- 나가기 버튼 또는 `Esc`
- 화면 가장자리의 위험 경고

미션 중 월드가 멈추지 않으므로 UI는 화면 전체를 완전히 가리지 않는다. 가장자리에서 붉은 괴물 접근 경고를 제한적으로 제공하되 정확한 방향과 거리를 알려주지는 않는다.

### 9.2 퓨즈

- 좌측에 퓨즈 3~5개
- 우측에 색상과 번호가 있는 슬롯
- 드래그 또는 클릭으로 삽입
- 잘못 삽입하면 즉시 실패 소음

### 9.3 차단기

- 이동하는 표시선과 목표 영역
- 지정 순서대로 키 또는 버튼 입력
- 타이밍 실패 시 스파크와 소음

### 9.4 CCTV 재부팅

- 노드 연결 또는 재시작 단계 3개
- 실패해도 큰 소음 대신 시간 손실 위주

### 9.5 시료 분류

- 라벨 모양과 위험 아이콘을 맞춰 보관 슬롯에 배치
- 제한시간은 없지만 잘못 분류하면 중간 소음

### 9.6 빌런 가짜 UI

외부에서 관찰할 때 정상 미션과 같은 시간과 애니메이션을 사용한다. 빌런 본인에게는 UI 안쪽에 작게 실제 강화 축과 결과를 표시한다.

## 10. 감염과 해독제 UI

### 10.1 감염

- 우측 하단에 큰 숫자 타이머
- 60초 이하 노랑, 30초 이하 적색 점멸
- 화면 가장자리 비네팅은 설정에서 감소 가능
- 주기적 심장 박동과 자막
- 현재 백신실 방향은 자동으로 알려주지 않으며 지도에서 확인

### 10.2 제작기

```text
백신 제작기 A
상태: 제작 중
남은 시간: 02:31
완료 후 누구나 가져갈 수 있습니다.
```

### 10.3 해독제 사용

- `R`을 누르면 1.5초 원형 진행 표시
- 이동 시 `사용이 중단되었습니다` 표시
- 성공 시 타이머와 감염 효과 즉시 제거

## 11. 회의와 투표

### 11.1 토론 화면

```text
┌──────────────────────────────────────────────────────────┐
│ 긴급 단톡방                          토론 01:18          │
├───────────────────────┬──────────────────────────────────┤
│ 생존 참가자           │ [파랑] 실험실 A에 붉은 연기 봄  │
│ 1 파랑                │ [노랑] 아까 초록이 거기 있었음   │
│ 2 노랑                │                                  │
│ 3 초록                │                                  │
│ 4 빨강                │                                  │
│ 5 보라                │                                  │
│ 6 주황                │                                  │
├───────────────────────┴──────────────────────────────────┤
│ 메시지 입력...                          [전송]           │
└──────────────────────────────────────────────────────────┘
```

- 사망·퇴출자는 참가자 목록에서 상태만 표시하고 채팅을 볼 수 없다.
- 최대 글자 수와 초당 메시지 수를 제한한다.
- 욕설 필터는 MVP에서 선택 사항이지만 신고 기능 없는 공개 배포는 피한다.

### 11.2 투표 화면

- 살아 있는 플레이어 카드
- 색상, 번호, 닉네임
- 한 명 선택 또는 기권
- 확인 전에는 변경 가능
- 확인 후에도 제한시간 내 변경 허용
- 누가 누구에게 투표했는지는 결과에서 MVP 기준 공개

### 11.3 결과

- 퇴출자 또는 `동률 — 아무도 퇴출되지 않았습니다`
- 역할은 공개하지 않음
- 다음 회의까지 쿨타임 안내
- 5초 후 월드 복귀

## 12. 유령 UI

- 화면 톤을 청회색으로 변경
- 상단에 `유령 — 살아 있는 플레이어와 대화할 수 없습니다.` 표시
- 자기 미션만 지도와 목록에 표시
- 공유 오브젝트 프롬프트 숨김
- 유령 채팅은 별도 탭으로 제공
- 벽 통과 시 화면이 어지럽지 않도록 카메라는 일반 플레이와 동일하게 유지

## 13. 결과 화면

1. 승리 진영과 이유
2. 모든 역할 공개
3. 주요 수치
4. 사건 타임라인
5. 발견한 단서와 놓친 단서
6. 다시 플레이·로비·나가기

## 15. UI 시각 규칙

- 일반 생존자 정보: 청록·백색
- 경고: 주황
- 즉시 위험·감염: 적색
- 빌런 전용 정보: 자주색과 적색 조합
- 유령: 청회색
- 성공: 녹색만 쓰지 않고 체크 아이콘 병행
- 실패: 적색만 쓰지 않고 X 아이콘과 문장 병행

본문은 어두운 반투명 패널 위에 높은 대비로 표시한다. 장식용 글꼴은 로고에만 사용하고 본문은 가독성 좋은 한글 산세리프를 사용한다.

## 17. UX 완료 기준

- 처음 플레이한 사람이 별도 설명 없이 이동과 첫 미션을 시작할 수 있다.
- 감염된 플레이어가 3초 안에 남은 시간과 해독제 보유 여부를 파악한다.
- 빌런 UI가 생존자 클라이언트에 보이지 않는다.
- 프로젝트 단계 변화가 소리 없이도 인지된다.
- 회의에서 남은 시간, 참가자와 자기 투표 상태가 항상 보인다.
- 1280×720에서도 필수 정보가 겹치지 않는다.
- 색상을 구분하지 못해도 아이콘과 번호로 플레이 가능하다.
